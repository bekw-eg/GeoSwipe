# GeoSwipe

Офлайн-игра на Flutter: изучение геометрии через движение, а не через выбор ответа.
Android — основная платформа. Веб-версия предназначена для удобного просмотра и разработки.

## Что работает

- **Играть:** 30 последовательных задач: по 10 на углы и треугольники, Пифагора и длины, тригонометрию. Девять заданий с вращением луча или построением фигуры, 21 — с вычислением ответа. Перетаскивайте ручки; для луча доступен ползунок. Жест вне ручек перелистывает открытые задания или прокручивает карточку.
- **Карта обучения:** три раздела, предварительные знания и реальные статусы прохождения. Изначально доступен первый уровень; успешная проверка открывает следующий. К открытым заданиям можно вернуться. Полный [каталог и условия проверки](docs/learning-levels.md).
- **Повторение:** новые параметры для всех 30 учебных целей, расписание через 1, 3 и 7 дней, возврат к более ранней стадии после ошибок. Ранняя тренировка доступна отдельно от интервального подтверждения.
- **Профиль:** реальные количества решённых уровней, подтверждённых навыков, заданий без подсказок, ошибок по темам и задач к повторению. Правила показателей доступны на экране.
- Три ступени помощи для каждого уровня: вопрос, формула/правило, другой разобранный пример. Объяснение с подстановкой после успешной проверки; история попыток, помощь и расписание сохраняются локально.
- Русский интерфейс, собственная отрисовка фигур, локально включённый Roboto и тёмная тема. Регистрация, серверы и сетевые запросы приложения не нужны.

[Игровой экран](docs/screenshots/play.png) — рендер виджетного теста для экрана 390 × 844, масштаб изображения 2×.

## Запуск

Требуются Flutter **3.44.6** / Dart **3.12.2**, Android SDK и JDK 17. Зависимости закреплены в `pubspec.lock`.

```sh
flutter pub get
flutter run
```

Подключите Android-устройство с USB-отладкой или запустите эмулятор. Для просмотра в браузере:

```sh
flutter run -d chrome
```

Android-приложение полностью работает без интернета, включая первый запуск после установки. Сеть требуется инструментам разработки для установки SDK и зависимостей. Веб-просмотр требует загрузки ресурсов с локального сервера; полноценное офлайн-кеширование веб-версии не реализовано. CanvasKit поставляется из локальной сборки, шрифты включены в приложение.

## Управление и математика

В основном курсе неподвижный луч OA направлен вправо; в повторных вариантах его направление меняется. Угол и ползунок отсчитываются **против часовой стрелки от OA** в диапазоне `[0°, 360°)`. В центре предусмотрена мёртвая зона, чтобы нулевой вектор не менял направление. Вращение начинается только рядом с точкой B; остальная область фигуры доступна для свайпа. На маленьком экране или при увеличенном шрифте карточка прокручивается, чтобы все действия оставались доступны; любой уровень также открывается с карты.

Для первых двух поворотов проверка использует минимальное угловое расстояние с включительным допуском **±2°** и техническим epsilon `1e-9°`. Например, для цели 45° принимается весь интервал 43°–47°. В заданиях на тупой угол и косинус проверяется **меньший угол** между лучами; зеркальные положения тоже подходят. Подпись «Твой угол» показывает поворот против часовой стрелки. Ползунок имеет шаг 0,1°, проверяется исходное значение.

Построения проверяются по углам, длинам и отношениям сторон, независимо от координат ручки. Вырожденные треугольники отвергаются. Разрешены все удовлетворяющие условию положения, в том числе отражения. Допуски указаны в карточке: для составных построений угол ±1°, равные стороны с разностью до 0,05, отношения ±0,01. Целочисленные задачи требуют точного значения; десятичные — округления до 0,01 с абсолютным допуском ±0,005. Можно использовать десятичную запятую или точку. NaN и бесконечность не принимаются.

Целевое число в построении является условием задачи. Неизвестные длины и углы в вычислительных задачах скрыты. Объяснение появляется после успешной проверки, подсказки открываются по очереди и не подставляют решение. Завершённую попытку нельзя засчитать повторно нажатием кнопки.

**Не изучен**, **изучается**, **решается с подсказками**, **решается самостоятельно** и **подтверждён повторением** — отдельные состояния. Освоение требует самостоятельной базы и трёх самостоятельных повторений в назначенные сроки. Все правила, формулы статистики, генерация вариантов и миграция описаны в [обучающей системе](docs/learning-system.md).

## Архитектура

```text
lib/
  core/       ChangeNotifier-контроллер, тема, чистая математика
  models/     Level, MathTopic, PuzzleState, AttemptResult, прогресс
  data/       каталог уровней, репозиторий и адаптер локального хранилища
  features/   play, learning, review, profile
  widgets/    интерактивный CustomPainter и общие компоненты
```

`core/geometry/` не зависит от Flutter: формулы, неизменяемые сцены и математические ограничения. `GeometryViewport` переводит координаты между сценой и экраном с одинаковым масштабом по осям; `GeometryBoard` обрабатывает ручки, `GeometryPainter` рисует. `RotatePuzzle`, `DragPuzzle`, `AnswerPuzzle` используют общую карточку с условием, проверкой, подсказкой и перезапуском. См. [описание API и пример новой задачи](docs/geometry-engine.md). Контроллер управляет состоянием и передаёт снимки репозиторию; `ProgressStore` подменяется в тестах. Новые уровни и главы добавляются в `level_catalog.dart` со стабильными уникальными идентификаторами.

## Локальные данные

`SharedPreferencesAsync` хранит JSON под ключом `geoswipe.progress`, схема **version 2** с миграцией v1. Сохраняются открытые уровни, подробная история проверок, использованные ступени помощи, состояния навыков, сроки повторений, номера вариантов и последний уровень. Положение незавершённой фигуры и введённый ответ сбрасываются; подсказки и условие незавершённого повторения восстанавливаются.

Записи выполняются последовательно. При ошибке записи статистика остаётся в памяти и отображается кнопка повтора. Повреждённое сохранение или неизвестная версия **не перезаписываются**: приложение предупреждает об игре без сохранения. Миграция v1 сохраняет счётчики и доступ к уровням, назначает новые сроки и не выдумывает отсутствующую историю; данные неизвестных уровней сохраняются при чтении и записи. Удаление приложения или его данных удаляет прогресс; экспорта и облачной синхронизации нет.

Новый курс сохраняет совместимые ID `angle-45`, `angle-90`, `angle-135`, `triangle-right`, `pythagoras-3-4`. Ранее решённые совместимые задания остаются доступны, даже если новые предпосылки ещё не пройдены; их непосредственные продолжения тоже открыты. Записи снятых с каталога `angle-60`, `angle-180`, `angle-270`, `angle-315` сохраняются без присвоения их результатов новым задачам. Последний снятый или закрытый уровень заменяется в навигации первым уровнем; накопленные данные не удаляются. Разблокировка дополняется из сохранённых решений и сохраняется в v2; ранее открытые задания остаются доступны.

## Проверки

```sh
dart format lib test
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
```

Тесты покрывают геометрию и границы допуска, подсказки, освоение и повторение, сохранение/восстановление, ошибки чтения и записи, жесты луча и вертикальной ленты, навигацию, компактные и горизонтальные экраны и увеличенный шрифт. Виджетные тесты сохраняют проверочные изображения в игнорируемую папку `build/ui/`; это не эталонные тесты по пикселям. CI запускает те же проверки и Android-сборку.

На Windows анализатор Flutter 3.44.6 может аварийно завершаться с `FormatException` в LSP, если путь проекта содержит кириллицу. Локальный обход — directory junction с латинским путём к той же папке (без переноса файлов):

```powershell
New-Item -ItemType Junction -Path C:\dev\GeoSwipe -Target (Get-Location).Path
Set-Location C:\dev\GeoSwipe
flutter analyze
```

Родительская папка `C:\dev` должна существовать. Здесь проверки выполнены через `C:\Users\zdeat\codex-workspaces\geoswipe-foundation`.

Debug APK: `build/app/outputs/flutter-apk/app-debug.apk`. Публикация в магазине требует собственной release-подписи; текущий шаблон использует debug-ключ для локальных сборок. iOS-проект пока не создан.
