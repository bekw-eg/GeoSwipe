# GeoSwipe

Офлайн-игра на Flutter: изучение геометрии через движение, а не через выбор ответа.
Android — основная платформа. Веб-версия предназначена для удобного просмотра и разработки.

## Что работает

- **Играть:** вертикальная лента из шести уровней на углы: 45°, 90°, 135°, 180°, 270° и 315°. Перетаскивайте точку B или используйте ползунок. Жест вне точки B перелистывает уровни на обычном мобильном экране.
- **Карта обучения:** выбор любого доступного уровня, реальные статусы прохождения. Для треугольников и тригонометрии явно указано, что уровней пока нет.
- **Повторение:** отдельные попытки для решённых задач. Сначала предлагаются ещё не освоенные уровни; можно выбрать задачу вручную.
- **Профиль:** решённые уровни, освоение, число проверок и доля верных ответов. До первой попытки процент не вычисляется.
- Подсказки, ошибки с величиной отклонения, объяснение после успешной проверки, перезапуск попытки и локальное сохранение статистики.
- Русский интерфейс, собственная отрисовка фигур, локально включённый Roboto и тёмная тема. Регистрация, серверы и сетевые запросы приложения не нужны.

[Игровой экран](docs/screenshots/play.png) — рендер виджетного теста для экрана 390 × 844, масштаб изображения 2×.

## Запуск

Требуются Flutter **3.44.6** / Dart **3.12.2**, Android SDK и JDK 17. Зависимости закреплены в `pubspec.lock`.

```sh
flutter pub get
flutter run
```

Подключите Android-устройство с USB-отладкой или запустите эмулятор. Для просмотра в браузере:

```sh
flutter run -d chrome
```

Android-приложение полностью работает без интернета, включая первый запуск после установки. Сеть требуется инструментам разработки для установки SDK и зависимостей. Веб-просмотр требует загрузки ресурсов с локального сервера; полноценное офлайн-кеширование веб-версии не реализовано. CanvasKit поставляется из локальной сборки, шрифты включены в приложение.

## Управление и математика

Неподвижный луч OA направлен вправо. Угол отсчитывается **против часовой стрелки** в диапазоне `[0°, 360°)`. В центре предусмотрена мёртвая зона, чтобы нулевой вектор не менял направление. Вращение начинается только рядом с точкой B; остальная область фигуры доступна для свайпа. На маленьком экране или при увеличенном шрифте карточка прокручивается, чтобы все действия оставались доступны; любой уровень также открывается с карты.

Проверка использует минимальное угловое расстояние с включительным допуском **±2°** и техническим epsilon `1e-9°`. Например, для цели 45° принимается весь интервал 43°–47°. Полные обороты математически эквивалентны; переход через 0° обрабатывается корректно. NaN, бесконечность и некорректные допуски не принимаются. Ползунок имеет шаг 0,1°, подпись текущего угла округляется до десятых, проверяется исходное значение.

Целевое число является условием задачи. Объяснение решения появляется только после успешной проверки; подсказки не устанавливают угол автоматически. Завершённую попытку нельзя засчитать повторно нажатием кнопки.

**Решено с подсказкой**, **решено самостоятельно** и **освоено** различаются. Освоение требует минимум двух самостоятельных успешных попыток, хотя бы одной из них в разделе повторения. Это простое правило закрепления, а не полноценная оценка долгосрочного знания. Повторение начинается с нового состояния фигуры.

## Архитектура

```text
lib/
  core/       ChangeNotifier-контроллер, тема, чистая математика
  models/     Level, MathTopic, PuzzleState, AttemptResult, прогресс
  data/       каталог уровней, репозиторий и адаптер локального хранилища
  features/   play, learning, review, profile
  widgets/    интерактивный CustomPainter и общие компоненты
```

`angle_math.dart` не зависит от Flutter. Модели отделены от виджетов; новые типы задач можно добавлять через `PuzzleKind`. Контроллер управляет состоянием и передаёт снимки репозиторию; `ProgressStore` подменяется в тестах. Новые уровни и главы добавляются в `level_catalog.dart` со стабильными уникальными идентификаторами.

## Локальные данные

`SharedPreferencesAsync` хранит JSON под ключом `geoswipe.progress`, схема **version 1**. Сохраняются проверки, успешные решения, использование подсказок при решении, самостоятельные повторения и последний открытый уровень. Положение незавершённого луча и активная попытка после перезапуска не восстанавливаются.

Записи выполняются последовательно. При ошибке записи статистика остаётся в памяти и отображается кнопка повтора. Повреждённое сохранение или неизвестная версия **не перезаписываются**: приложение предупреждает об игре без сохранения. Для новой версии схемы нужно добавить явную миграцию в репозиторий; данные неизвестных уровней сохраняются при чтении и записи. Удаление приложения или его данных удаляет прогресс; экспорта и облачной синхронизации нет.

## Проверки

```sh
dart format lib test
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
```

Тесты покрывают геометрию и границы допуска, подсказки, освоение и повторение, сохранение/восстановление, ошибки чтения и записи, жесты луча и вертикальной ленты, навигацию, компактные и горизонтальные экраны и увеличенный шрифт. Виджетные тесты сохраняют проверочные изображения в игнорируемую папку `build/ui/`; это не эталонные тесты по пикселям. CI запускает те же проверки и Android-сборку.

На Windows анализатор Flutter 3.44.6 может аварийно завершаться с `FormatException` в LSP, если путь проекта содержит кириллицу. Локальный обход — directory junction с латинским путём к той же папке (без переноса файлов):

```powershell
New-Item -ItemType Junction -Path C:\dev\GeoSwipe -Target (Get-Location).Path
Set-Location C:\dev\GeoSwipe
flutter analyze
```

Родительская папка `C:\dev` должна существовать. Здесь проверки выполнены через `C:\Users\zdeat\codex-workspaces\geoswipe-foundation`.

Debug APK: `build/app/outputs/flutter-apk/app-debug.apk`. Публикация в магазине требует собственной release-подписи; текущий шаблон использует debug-ключ для локальных сборок. iOS-проект пока не создан.
