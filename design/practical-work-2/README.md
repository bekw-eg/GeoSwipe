## Дизайн-система

- Основной цвет — `#A897FF`, дополнительный — `#6D9FFF`, акцент успеха — `#66E3CD`.
- Фон — `#0C1425`, карточки — `#151F35`, приподнятые поверхности — `#1C2942`.
- Основной текст — `#F4F5FC`, вторичный — `#A4B0C7`. Предупреждение — `#FFCF91`, ошибка — `#FFB4AB` вместе с объяснением.
- Roboto: заголовки 32/38 и 27/34, название карточки 21/28, основной текст 16/24, дополнительный 14/21, подписи 12/18.
- Сетка: четыре колонки, поля 24 px, промежутки 16 px. Карточка: радиус 24; кнопка: 17 и высота 54; поле: 16. Интерактивная область — не меньше 48 px.
- Варианты кнопок: primary, secondary, success, disabled, pressed. Поля: empty, filled, error. Нижняя навигация: четыре активные вкладки. Текст компонентов меняется через свойства; цвета и радиусы связаны с переменными.

## Как пройти прототип

Откройте ссылку запуска или выберите **01 · Splash** в файле и нажмите **Present ▶**.

1. «Начать» → «Войти в профиль» → «Открыть курс».
2. «Угол 45°» → «Начать задачу».
3. «Переместить точку B» → «Проверить».
4. «Перейти в профиль»: показано одно самостоятельное решение и ноль освоенных навыков.

Дополнительно проверены подсказка, повтор после ошибки, добавление/удаление избранного, регистрация с пустым именем, поиск без результатов, Create/Edit заметки и все комбинации двух переключателей настроек.

Построение демонстрирует два положения луча: 25° и 45°. Цель 45° и допуск ±2° указаны до проверки как условие; объяснение появляется после успеха. Решение с помощью не считается самостоятельной базой для освоения.

## Границы учебного прототипа

Тариф Starter запрещает `SET_VARIABLE` и `CONDITIONAL` в прототипе. Поэтому используются обычные переходы между заранее подготовленными состояниями. Ветки демонстрации независимы: произвольные комбинации избранного, заметок и прогресса между ними не сохраняются. Формы заполняются образцом по нажатию, перемещение точки показано кнопкой. Это интерактивный дизайн, а не работающая регистрация, редактор текста или математический движок.

Login и Registration показывают выбор и создание **локального профиля**, без почты, пароля или сервера. Новые профили, поиск, избранное, заметки и настройки — проектные экраны этой практической работы; их реализация во Flutter не добавлялась. Данные установленного приложения не меняются.

## Исходники и проверка

- `code.js` — модель экранов, компоненты, компилятор сценариев Starter и поэтапная сборка через Figma Plugin API. Не требует пакетов или сетевых запросов.
- `prototype-map.json` — граф, считанный из созданного Figma-файла, плюс результаты проверки шрифта, редактируемых слоёв и границ текста.
- `verify.cjs` — сопоставление всех переходов с исходниками, восемь полных/негативных сценариев и достижимость всех 18 основных экранов.
- `evidence/` — реальные экспорты Figma: Home, Puzzle и витрина дизайн-системы.

```sh
node --check design/practical-work-2/code.js
node --check design/practical-work-2/verify.cjs
node design/practical-work-2/verify.cjs
git diff --check
```

Проверка проведена 20.10.2026. Скрипт использует сохранённые реальные связи Figma. Дополнительно основной сценарий из восьми переходов пройден кликами в настоящем плеере Figma Present: Splash → Login → Home → List → Detail → Puzzle → Result → Profile. Итог — `node-id=5-43`, одна самостоятельная задача и ноль освоенных навыков; снимок сохранён в `evidence/scenario-profile.png`. Проверки Flutter и Android-сборка не запускались: код приложения, зависимости и Dart-файлы не изменены.

Для резервного повторного создания можно использовать `manifest.json` как development plugin. Если Figma требует `id`, создайте собственный development plugin и перенесите **его фактический Figma id** в манифест. Генератор создаёт новую страницу, не удаляет существующие страницы и не перезаписывает данные приложения. Основной готовый результат уже доступен по ссылке выше.
