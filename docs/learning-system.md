# Обучение, освоение и повторение

Система работает офлайн. Статистика, доступность уровней и расписание берутся
из сохранённых результатов, без демонстрационных данных и произвольных процентов.

## Навыки и подсказки

В текущем курсе **30 учебных целей**: каждая задача каталога представляет отдельный
навык. `Level.skillId` совпадает со стабильным `Level.id`; `topicId` объединяет
навыки в три темы. Повторные варианты сохраняют этот ID и проверяют тот же принцип.
Это не оценка освоения всей геометрии: подтверждение относится к конкретной цели
из [каталога](learning-levels.md).

В `data/lesson_help.dart` для каждой цели заданы ровно три ступени:

1. Направляющий вопрос.
2. Необходимое правило или формула с символическими переменными.
3. Разобранный аналогичный пример с другими исходными данными.

Ступени открываются только по порядку. Поэтому сохранённый `hintCount = N`
однозначно означает использование ступеней 1…N. Подсказка относится ко всей
незавершённой задаче: изменение ввода, сброс фигуры, выход с экрана и перезапуск
приложения её не отменяют. Обычная задача и повторение хранят помощь раздельно.
После успешного решения история сохраняет число подсказок; новая попытка может
начаться без помощи. Объяснение текущего решения показывается **только после
успешной проверки**, включая формулу и подстановку. Для построений используются
реальные длины и углы принятой фигуры, в том числе отражённой; округлённые значения
помечены `≈`. Неверный численный ответ не раскрывает ожидаемое число.

## Состояния навыка

| Состояние | Правило |
| --- | --- |
| Не изучен | Не было открытия/взаимодействия или проверки этой цели |
| Изучается | Начата работа или последняя проверка была неверной |
| Решается с подсказками | Последнее успешное решение использовало хотя бы одну ступень |
| Решается самостоятельно | Есть самостоятельное решение, но цикл повторений ещё не завершён |
| Подтверждён повторением | Есть самостоятельная база и три успешных самостоятельных повторения после назначенных сроков |

Любое верное решение открывает следующий уровень. Это отдельно от освоения.
Ошибки и помощь могут понизить состояние навыка, но не отнимают завершённые уровни
и не закрывают уже открытые задания. Неверные попытки до самостоятельного решения
сами по себе не делают его решением с подсказкой: помощь учитывается отдельно.

## Интервалы и часы

`AppController(repository, clock: () => timestamp)` принимает часы. В приложении
по умолчанию используется `DateTime.now`; в тестах время изменяется явно.
В хранилище все моменты времени — UTC, в интерфейсе дата и время выводятся в часовом
поясе устройства. День означает ровно 24 часа, интервалы идут **от фактической
успешной проверки**, включая просроченные задания.

| `reviewStage` | Следующий интервал | Переход после самостоятельного повторения в срок |
| --- | --- | --- |
| 0 | 1 день | 1 |
| 1 | 3 дня | 2 |
| 2 | 7 дней | 3, навык подтверждён |
| 3 | 7 дней, поддержание | 3 |

Первое успешное решение назначает повторение через день. Если оно было с помощью,
первое последующее самостоятельное решение создаёт самостоятельную базу и заново
назначает один день; оно ещё не является первым подтверждающим повторением.

Для продвижения срока нужно начать повторную задачу **не раньше** `dueAt`, решить
её самостоятельно и без ошибок в этой сессии. Ранняя тренировка доступна и
записывается в историю, но не продвигает и не откладывает существующее расписание.
Если срок наступил уже после открытия ранней тренировки, нужно открыть новую
сессию повторения. Самый ранний срок выбирается первым; ручной выбор тоже доступен.

Каждая неверная проверка понижает стадию на одну, минимум до 0, снимает подтверждение
и назначает интервал этой более ранней стадии от момента ошибки. Если до ошибки
ещё не было решения, расписание не создаётся. Исправление после ошибки возвращает
самостоятельную базу, но в той же сессии не засчитывает интервальное продвижение.
Решение с подсказкой сбрасывает стадию до 0 и назначает один день.

При наступлении ближайшего срока приложение обновляет интерфейс таймером; при
возвращении приложения на экран расписание также пересчитывается. Для логики
сравнения достаточно подставить часы и вызвать `refreshTime()`; ждать реальных
дней в тестах не нужно. Таймер принадлежит экрану приложения и освобождается при его закрытии.

## Повторные задания

`data/review_variants.dart` строит варианты для всех 30 целей. В вычислениях
меняются углы, длины, координаты, отношения или данные прикладной задачи. В
построениях меняется масштаб и числовая конфигурация; условия равенства,
перпендикулярности и отношений сохраняются. Для угла по косинусу меняется целевой
косинус, для острого поворота — целевой угол. В задачах о прямом/тупом угле
определение угла сохраняется, меняются размеры конфигурации и исходное направление
OA. И показание угла, и ползунок отсчитываются от этого луча, а не от оси экрана.

Номер варианта воспроизводим и сохранён для каждой цели. После успешной проверки
следующая сессия получает следующий номер. Незавершённый вариант после перезапуска
сохраняет номер и подсказки; численный ввод и положение фигуры сбрасываются.
Некоторые ограниченные угловые параметры циклически повторяются после серии
вариантов; соседние вычислительные задания имеют разные исходные данные.
Допуски проверяются математическими ограничениями: точные целые или ±0,005 для
ответов до сотых, остальные допуски показаны в карточке. Тестовые решения
вычисляются отдельно от `constraint.expected`.

## Правила статистики

| Показатель | Источник и расчёт |
| --- | --- |
| Уровней решено | Уникальные активные `levelId` с `completions > 0` |
| Навыков освоено | Активные цели в состоянии `confirmed` |
| Заданий без подсказок | Уникальные активные уровни с `independentCompletions > 0`, включая самостоятельные повторения |
| Всего проверок | Сумма `attempts` по сохранённым уровням, включая снятые с каталога |
| Ошибки по темам | Сумма `attempts − completions` по активным уровням соответствующей темы |
| Задач к повторению | Решённые активные цели с `dueAt ≤ now`; одна цель считается один раз |

Каждое нажатие проверки незавершённого задания — одна попытка. После успеха
повторные нажатия, изменение ввода и попытки изменить фигуру не создают записей.
Сброс завершённого повторения начинает следующий вариант. Закрытую/старую сессию
нельзя отправить снова. Каждая новая запись истории содержит `levelId`, `topicId`,
UTC-время, результат, число открытых ступеней, обычный/повторный режим,
признак допуска к интервальному продвижению, номер варианта и численный ввод.
Для построений формула объяснения использует текущую принятую сцену, а история
фиксирует исход проверки; координаты фигуры в историю не записываются.

## Хранилище и миграция

Используется существующий `SharedPreferencesAsync`, ключ `geoswipe.progress`,
JSON **version 2**. Для небольшого локального курса хранится единый согласованный
снимок: накопленные счётчики, открытые уровни, последний уровень, история проверок,
состояния навыков и сроки, незавершённые подсказки, номера повторных вариантов.
Записи выполняются последовательно; при ошибке данные остаются в памяти и
доступна повторная запись. Удаление данных приложения удаляет прогресс.

Миграция v1 сохраняет все исходные счётчики, неизвестные/снятые ID и доступные
уровни. По старым счётчикам восстанавливается изучение/решение с помощью/самостоятельно.
Старое правило «два решения, одно повторное» **не даёт** нового подтверждения:
v1 не сохраняла даты и другие параметры задач. Для старых решённых целей
назначается первое повторение через день от миграции; срок сразу записывается,
поэтому следующий запуск не сдвигает его. События прошлого не выдумываются:
суммарные показатели включают v1, подробная история содержит только новые проверки.

Неизвестная версия, повреждённые данные или противоречивые состояния не
перезаписываются пустым прогрессом. При ошибке чтения приложение разрешает
временную игру без записи и предлагает повторить чтение исходного сохранения.

## Проверка полного пути

`learning_system_test.dart` проверяет новые данные, границы сроков до микросекунды,
переходы стадий, ошибки, помощь, раннюю тренировку, миграцию и восстановление.
Отдельный сквозной тест пишет JSON в настоящий временный файл, создаёт новый
репозиторий/контроллер, восстанавливает результаты и выполняет назначенное повторение.
Для каждой из 30 целей проверяются четыре новых варианта независимыми решениями.

`learning_journey_ui_test.dart` проходит интерфейс: новый пользователь → подсказка →
запись → перезапуск до проверки → восстановление помощи → решение → перезапуск →
наступление срока → новое условие → самостоятельное решение → статистика →
восстановление результата. Снимки получены из работающих виджетов этого теста
при управляемых часах, а не из демонстрационной модели приложения:

- [Повторная задача с новым углом](screenshots/learning-review.png)
