# GeoSwipe бойынша практикалық жұмыс 1

Қазақ тіліндегі техникалық тапсырма және жоба есебі. Титул бетіндегі оқу орны, орындаушы, топ және оқытушы жолдарын студент өзі толтырады.

- [Word құжаты](GeoSwipe_technical_specification_kk.docx) — 22 бет, тапсыруға арналған негізгі файл.
- [Мәтіндік нұсқа](report.kk.md) — мазмұнды Git арқылы қарап, редакциялауға арналған көшірме.
- [Use Case](use-case.drawio), [бизнес-процесс](business-process.drawio), [User Flow](user-flow.drawio) — diagrams.net арқылы өңделетін диаграммалар.
- `figures/` — құжатқа енгізілген диаграммалар және нақты Flutter widget тесттерінің төрт суреті.

Есептің техникалық негізі — `origin/main`, `ce561e6`. Басқа feature тармақтарындағы өзгерістерді сипаттамайды. 14 жобалық экран төрт қолданыстағы бөлімнен және карточка көріністерінен ажыратылып көрсетілген; жоспарланған беттер іске асқан мүмкіндік ретінде берілмейді.

## Тексеру

19.10.2026 күні осы негізде орындалды:

| Тексеру | Нәтиже |
| --- | --- |
| `flutter pub get` | Өтті |
| `flutter analyze` | Өтті, No issues found |
| `flutter test --reporter expanded` | Өтті, 145 тест |
| `flutter build apk --debug` | Өтті, debug APK жиналды |
| Dart пішімдеуі | Қолданылмайды, Dart файлдары өзгермеді |
| Word орналасуы | Word арқылы PDF рендері және 22 бетті PNG түрінде визуалды тексеру |
| `git diff --check` | Өтті |

SDK XML нұсқалары туралы Android құрастыру ескертуі болды, бірақ жинақ сәтті аяқталды. Нақты Android құрылғысы қосылмаған және қолжетімді AVD бейнесі жоқ; құрылғыдағы іске қосу, жүйелік Back, ұшақ режимі, өнімділікті өлшеу мен толық TalkBack аудиті орындалмады. Word рендеріне Microsoft Word және bundled Poppler қолданылды; стандартты `render_docx.py` осы Windows runtime ішінде LibreOffice болмағандықтан орындалмады.

Қолданбаның Dart коды, сақтау схемасы және пайдаланушының жергілікті деректері өзгертілмеді. APK, уақытша PDF/PNG беттері және тест журналдары репозиторийге енгізілмейді.
